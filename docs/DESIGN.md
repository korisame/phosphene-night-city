# Night City showcase

Experience mode. This new web surface inherits the approved night-city artwork;
DESIGN.md at the repository root continues to govern the native app.

Near-black from the actual OLED night scene. Ice-white body copy, warm yellow
controls drawn from the jacket, restrained magenta details already in the art.
Self-hosted Barlow Condensed for large film-title lettering; a native readable sans
for prose. Typography max6rem, strong hierarchy, deliberate whitespace and thin
rules rather than boxes. No camera drift, zoom, parallax or automatic page motion.
The 24-second film excerpt plays only on request, with pause, controls, poster,
loading/error feedback and reduced-motion respect. Stills remain useful without JS.

The current wallpaper is v7. App1.9.1 is a separate identity. All downloads,
requirements, source and credits must remain available and clearly labelled on
mobile. Actual app screenshots contain no desktop, accounts or private files.
