# Phosphene native UI

Refinement of the original macOS visual language, implemented by Rust through AppKit. Operate mode for Library and status controls, with media as the primary content.

Use semantic AppKit colors and San Francisco typography, native rounded buttons, the existing Phosphene icon and SF Symbols. Reserve system accent for selection, primary actions and current playback. Rounded 16:9 thumbnails, 16pt grid gaps, clear selected outlines, visible in-use badges and secondary labels. Inspector groups preview, title, compact specifications, current display, optimization and actions. A native transient material popover restores the status icon's graphical panel. No webview, decorative cyberpunk skin or always-loaded view tree. Preserve light/dark appearance, keyboard focus and descriptive accessibility labels.
